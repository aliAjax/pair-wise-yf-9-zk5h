# 桌游规则遗忘点卡片库

一个纯前端本地应用，用来管理桌游收藏中的规则遗忘点、常见争议、开局准备和计分提醒。支持按最近未玩、人数范围和复杂度筛选，并在详情里展示聚会前快速复习卡片。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 讲解接力牌

每款游戏详情里可切到「讲解接力」标签，挂出一张属于本场的接力牌：

- 挂出时快照四类提醒，固定讲解顺序：**开局准备 → 容易忘的规则 → 常见争议 → 计分提醒**；之后修改复习卡片不影响本场进度。
- 到场者输入姓名签到，按到场顺序自动认领下一类；第 5 位起进入候补。
- 条目逐条点「讲完」，讲述人姓名和时间锁定在条目上，不可重开；也可一键记完整类。
- 正在讲的人点「临时离席」：未讲内容转给下一位（候补优先），已讲条目仍记在原讲述人名下；没有下一位在场时，剩余内容记为**断档**并写入历史，后来者可招领补讲。
- 四类全部讲完后本场接力结束；「重开」只清空接力牌，历史记录一直保留。

数据分三处存放在浏览器 localStorage，互不影响：

| key | 内容 |
| --- | --- |
| `zfl18-boardgame-rule-cards` | 桌游收藏与复习卡片 |
| `zfl18-relay-cards-v1` | 各游戏当前接力牌进度（关浏览器后继续） |
| `zfl18-relay-history-v1` | 只追加的讲解历史（认领、转交、断档、补讲等） |

## 测试

```
node test-relay.cjs    # 接力状态机：认领/离席转交/断档/补讲/持久化
node test-render.cjs   # 各状态下的界面渲染冒烟测试
```
